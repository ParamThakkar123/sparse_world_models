The playground idea

One finger, a few boxes kept apart. The closest box to the finger is almost always the one that moves. One number — distance — tells you the answer. Filters just pick which number.

What the AI is actually good at

Not detection — copying still boxes perfectly. Boxes the gate leaves OFF stay exactly put, so zero drift. Gap versus dense model grows with more boxes. Set boxes to 12 and watch.
